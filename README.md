# منيو بُنان (Bunnan Coffee)

موقع منيو ثابت (HTML + CSS + JS) بدون أي مكتبات.

## الملفات
- `index.html`: هيكل الصفحة
- `style.css`: التصميم والألوان والخطوط (خط Cairo)
- `app.js`: عرض الأقسام والبحث
- `menu.js`: **كل بيانات المنيو** (الأقسام، الأسماء، الوصف، الأسعار، مسار الصور)
- `images/`: صور الأصناف، و`logo.png` الشعار

## تعديل المنيو
- السعر أو الوصف: غيريه في `menu.js`.
- صنف جديد: انسخي أي بلوك `{ ... }` داخل `items` وعدلي القيم، وحطي الصورة في `images/` (يفضل نسبة 4:5، مثلاً 520×650).
- إخفاء صنف: أضيفي `"off": true` للصنف.
- قسم جديد: أضيفيه في `cats` واستخدمي نفس الاسم في `cat` للأصناف.

## الرفع على GitHub Pages
1. ارفعي كل الملفات والمجلدات لـ Repository.
2. Settings ثم Pages، اختاري Branch: main وFolder: / (root).
3. يطلع الرابط خلال دقيقة.

## للتجربة على جهازك
افتحي `index.html` في المتصفح مباشرة.
